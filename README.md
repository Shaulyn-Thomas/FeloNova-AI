# Felo Desk AI

AI-powered workplace productivity assistant.

## Project Overview

Felo Desk AI is an AI-powered workplace productivity assistant designed to help users with common workplace tasks and save time.

## Features

- Smart Email Generator
- Meeting Notes Summarizer
- AI Task Planner
- Responsive web application
- Editable AI-generated outputs
- Responsible AI guidance

## Tools Used

- Lovable
- GitHub
- TypeScript
- AI tools

## How to Use

1. Open the Felo Desk AI application.
2. Choose a tool from the sidebar.
3. Enter your information or request.
4. Generate the AI response.
5. Review and edit the response before using it.

## Responsible AI

AI-generated information should be reviewed by the user before it is used or shared. Users should check important details such as names, dates and commitments.
